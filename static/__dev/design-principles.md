Financial decision cockpit: SignalForge Pay should feel like a premium revenue operations instrument built for founders, not a generic fintech dashboard. Use deep navy/graphite surfaces, crisp hairline borders, one electric blue signal accent, restrained green only for positive financial movement, and amber only for caution. Support both light and dark modes, with dark as the hero. Pacing is tight and analytical. Cards are layered but flat enough to feel serious; medium radii, minimal glass, subtle shadows. Display type is confident and modern; body/UI copy is compact and neutral; monospace is reserved for amounts, API status, confidence and transaction IDs. Evidence, inference and recommended action must always be visually distinct.
